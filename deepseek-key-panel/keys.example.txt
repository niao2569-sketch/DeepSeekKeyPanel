# DeepSeek API Key 列表示例
#
# 用法：
#   python cli.py -f keys.txt
#   或把本文件改名为 keys.txt 后直接用（keys.txt 已在 .gitignore 里）
#
# 格式说明：
#   * 每行一个 Key
#   * 支持 "名称,Key" 或 "Key,备注" —— 逗号、制表符、分号、竖线都能当分隔符
#   * # 开头的行是注释，会被忽略
#   * 空行会被忽略
#   * 重复的 Key 会自动去重
#   * Bearer 前缀会被自动去掉

# ---- 下面都是假的，换成你自己的 ----

主力号,sk-00000000000000000000000000000002
sk-00000000000000000000000000000003,备用（9月充值）
客户A	sk-00000000000000000000000000000004
