余额曲线充值点（余额上升）
原理：每次成功查询会记录一条「时间 + 余额」快照，消耗 = 相邻两次快照中余额下降的部分之和，充值 = 上升部分之和。 快照只保存在本机浏览器里，换浏览器/清缓存就会丢。想要权威用量请看下面的官方接口。

        这个工具怎么处理你的 Key：
        
    
          
  • 所有请求都由你的浏览器或你本机的中转进程直接发往 api.deepseek.com / platform.deepseek.com，没有任何第三方服务器参与。

  • 本地服务只监听 127.0.0.1，只允许转发到上面两个域名，不记录也不落盘 Key。代码就在 src/deepseek_key_panel/server.py，可以直接审。

  • 小心截图分享：Key 和平台 Token 都在页面上，打码功能默认是开的。

ℹ️ 关于v1.0.0

      

        官方接口能力（已实测确认）：
        
    
          
  • GET https://api.deepseek.com/user/balance —— 用 API Key 查余额，返回 is_available 与各币种的总额/赠送/充值余额。支持跨域。
    • 
          
  • GET https://platform.deepseek.com/api/v0/usage/amount?month=&year= 与 .../cost —— 查真实 Token 用量与费用。需要用网页登录 Token，且没有 CORS 头，必须经本地中转。
    • 
          
  • DeepSeek 没有提供「用 API Key 查历史调用量」的接口 —— 官方文档只有余额。所以任何声称能直接用 API Key 出用量的工具，要么在爬网页登录态，要么在本地自己记账。
    • 
        

        相关开源项目（本面板未使用其代码，仅作参考）：
        
    
          
  • DeepSeekMonitorWindows —— Tauri/Rust 桌面监控，用量接口的调用方式参考了它
    • 
          
  • dsh-balance / dsh-bottom-info-bar / dsh-cost-meter —— DSH 插件形态
    • 
          
  • api-balance-checker-extension —— 浏览器扩展，多中转站适配
