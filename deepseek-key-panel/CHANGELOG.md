## [未发布]

### 新增
- **加密存储（主密码）**：Key、余额快照、用量记录、平台 Token 全部经
  AES-GCM-256 加密后才写入本机；密钥由主密码经 PBKDF2-SHA256（25 万次迭代）派生，
  每条记录使用随机盐与随机 IV。密码不写入任何地方，可勾选只在 sessionStorage
  保留以避免刷新后重复输入；支持立即锁定、修改密码、关闭加密
- **中英双语界面**：右上角可切换，也可用 `?lang=en` / `?lang=zh` 直接指定。
  切换语言采用重新加载的方式，避免维护反向翻译表
- **英文版 README**（`README.en.md`）—— 同时修掉了 README 里指向它、但此前并不存在的死链
- **中英双语项目简介**（`docs/intro.md`）—— 按长度分五档（GitHub About 字段 / 一句话 / 短版 / 标准版 / 长版），
  另附 Topics 建议与社交平台短文案
- 中文 Windows 终端下更友好的退出提示

### 修复
- **「无法保存 Key」**：旧逻辑把「是否保存」交给一个默认关闭、且藏在设置页的复选框，
  用户导入 Key 后刷新就全没了，看起来就是「存不上」。现在改为加密存储 + 明确的状态提示
- 动态重绘后界面会退回中文（翻译只在启动时跑过一次）；现在所有渲染函数都会自动重译
- 带变量的提示语（toast / confirm）不会翻译；现在通过 `tr()` 统一处理
- `README.md` 顶部的 `[English](README.en.md)` 指向不存在的文件，现已补齐

### 测试
- 新增 `tests/check_i18n.py`：校验 zh/en 词条键集合一致、ZH2EN 映射无失效、
  标记里的中文无遗漏 —— 把「漏翻」从肉眼检查变成 CI 能拦的错误
- 自检从 11 项增加到 12 项

## [1.1.0] - 2026-10-05

### 新增
- **可用性实测**：`GET /models` 快速验证 Key 能否真正访问 API（不消耗 token），
  可选深度实测 —— 真实调用一次 `chat/completions`（`max_tokens=1`）确认能调模型
- **余额预警**：可设阈值，跌破的 Key 整行高亮、余额标红、汇总卡计数；
  可选浏览器通知，余额回升后自动复位
- **标签分组**：一个 Key 可打多个标签，支持按标签筛选与批量选择
- **编辑弹窗**：替代原先的 `prompt()`，可改名/备注/标签/Key，Esc 关闭、Enter 保存
- **完整备份与恢复**：Key、标签、设置、快照历史、用量结果一次性导出/导入
- **导出纯 Key 列表**：当前筛选结果一行一个，便于喂给其他工具
- **一键清理无效 Key**：只删返回 401 的，余额不足/限流/网络失败的不动
- **用量增强**：近 3 个月费用对比、按天+按模型的 CSV 导出
- **命令行版 `cli.py`**：批量查询、`table/json/csv/txt` 四种输出、
  `--only` 过滤、`--models` 验证、`--threshold` 报警、分级退出码
- **桌面程序形态**：`app.py` 以无边框应用窗口打开，关窗自动退出；
  可用 PyInstaller 打包成免安装单文件 exe
- **开源配套**：MIT 许可、CHANGELOG、CONTRIBUTING、SECURITY、GitHub Actions CI 与发布流程

### 修复
- 月度用量汇总原先按「天」累加，当天数据不全时会与「按模型拆解」对不上；
  改为以接口返回的权威 `total` 为准（缺失时才回退到按天累加）
- 「近 N 天充值/消耗」会漏掉跨越窗口边界的变动（例如 6 天前的充值显示为 ¥0）；
  改为把窗口前最后一条快照作为计算基准
- 余额曲线上的充值点画在了错误的 Y 值上（用了充值金额而非充值后余额）
- 点「停止」会把在飞的 Key 全部标成查询失败；现在会还原它们原本的状态
- CLI 表格被无效 Key 的超长错误信息撑爆；现在按终端显示宽度截断
- CLI 用多个 `-k` 参数时自动编号会重复（两个 `Key-1`）；改为去重后统一编号
- CLI 文件不存在时退出码为 1，应为 2（参数/输入错误）

## [1.0.0] - 2026-10-05

### 新增
- 首个版本：单文件 HTML 面板 + 本地中转服务
- 批量导入 Key（粘贴 / txt / csv / json / 拖拽），自动去重、自动识别、自动剥离 `Bearer`
- 并发查询余额，状态区分（可用 / 余额不足 / Key 无效 / 限流 / 网络 / 官方异常）
- 按币种汇总余额，搜索、筛选、导出 CSV/JSON
- 余额快照曲线，推算消耗、充值、日均消耗与可用天数
- 官方用量接口（Token / 请求数 / 缓存命中 / 费用），按天与按模型拆解
- 本地中转服务：仅监听 `127.0.0.1`、域名白名单、不转发 Cookie、不落盘 Key
- 连接自检、自动刷新、亮暗主题
