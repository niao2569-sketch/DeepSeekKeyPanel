DeepSeek Key 面板 · 使用说明
================================
版本 1.2  ·  2026-10-06

这个文件夹里有两样东西：

  DeepSeekKeyPanel.exe          程序本体，双击就能用，不需要装任何东西
  deepseek-key-panel\           完整源代码（要发到 GitHub 就用这个）


一、最省事的用法
----------------
双击 DeepSeekKeyPanel.exe。

会弹出一个没有地址栏的窗口（看起来像个正经桌面程序）。
关掉窗口，程序会自动退出，不会在后台留东西。

如果 Windows 弹出「已保护你的电脑」：
    点「更多信息」→「仍要运行」
这是没买代码签名证书的单文件 exe 的常见待遇，不是病毒。
介意的话改用下面的便携版。

⚠️ 更新程序前请先关掉正在运行的窗口，否则文件被占用会覆盖失败。


二、界面语言
------------
窗口右上角有语言开关，点一下即可在中英文之间切换：

    ┌─────────────────┐
    │ ( 中文 )   EN   │
    └─────────────────┘

也可以在网址后面加 ?lang=en 或 ?lang=zh 直接指定。


三、怎么用
----------
1. 点开「导入 Key」，把 API Key 粘进去
   （一行一个；也可以带名字，比如  主力号,sk-xxxxxxxx）
2. 点「查询全部余额」
   余额、赠送额、充值额、状态一次看全
3. 想确认 Key 是不是真的能用，点「实测」
   查 /models 验证鉴权，不花一分钱；深度实测会真调一次模型
4. 每次查询会自动记录余额快照
   「用量与消耗」页能看消耗曲线、充值记录、还能用多少天
5. 想看官方 token 用量和费用，需要「平台登录 Token」，见第五节


四、数据保存在哪里（重点）
--------------------------
数据会自动保存到一个 INI 文件里：

    我的文档\DeepSeekKeyPanel\dskp.ini

不用手动保存，每次改动都会自动写进去；下次打开面板会自动读取并解密，
**不需要输入任何密码**。

怎么做到的：文件用 Windows DPAPI 加密，密钥由你的 Windows 账户派生。
也就是说：

  ✅ 打开就能用，不用记密码
  ✅ 别人把这个文件拷走也解不开（包括拷到别的电脑、别的 Windows 账户）
  ✅ 文件里看不到明文 Key

想换个位置存放，可以设置环境变量 DSKP_DATA_DIR 指向别的目录。

在「设置与诊断」页能看到文件的完整路径、大小、最后更新时间，
也可以一键删除数据文件。

如果需要更强的保护（比如防「别人趁你没锁屏用你的电脑」），
可以在同一页设置一个「主密码」，那样打开面板就需要先输密码。


五、查官方用量（可选）
----------------------
用 API Key 查不到历史用量 —— DeepSeek 官方没开放这个接口，
官方文档里只有余额。要查真实用量，得用网页登录态：

1. 浏览器登录 platform.deepseek.com
2. 按 F12 打开控制台，把面板里给的那段脚本粘进去回车
   （Token 会自动复制到剪贴板）
3. 回到面板「用量与消耗」页，粘到输入框，点「拉取官方用量」

这个 Token 是登录态，权限等同于你的账号，别发给任何人。


六、便携版
----------
DeepSeekKeyPanel-portable.zip 是备选方案。
解压后双击里面的 exe 即可，同样不需要安装。

什么时候用它：
    - 单文件版被杀毒软件误报时
    - 想启动快一点时
（单文件版每次启动都要把自己解压到临时目录，便携版不用）


七、安全
--------
· 所有请求都由你的电脑直接发往 api.deepseek.com 和 platform.deepseek.com
  不经过任何第三方服务器，不存在「把 Key 送去代查」
· 本地服务只监听 127.0.0.1，局域网和公网都访问不到
· 数据文件在磁盘上是加密的（见第四节）
· 如果不用本地服务、直接双击源码里的 index.html，
  数据会退回存在浏览器本地（可另设主密码加密）
· 导出的 CSV / 备份默认对 Key 打码
  「导出纯 Key」和「完整备份」是明文，会二次确认
  这两个文件等同于你的 Key 本身，别放网盘、别发人
· 截图分享前记得打码

九、想改代码
------------
需要 Python 3.8+（只改前端的话再加个 Node.js）。

    python run_panel.py            源码方式运行
    python tests/run_all.py        跑全部自检（14 项）
    python build.py --all          重新打包 exe + 便携版

详细说明看 README.md 和 CONTRIBUTING.md。


十、常见问题
------------
Q: 换了台电脑，数据还在吗？
A: 数据文件（dskp.ini）因为绑定 Windows 账户，换机器打不开。
   要迁移请用面板里的「导出完整备份」，在新机器上导入。

Q: 不启动本地服务能查余额吗？
A: 能。api.deepseek.com 的接口支持跨域，直接双击
   deepseek-key-panel\src\deepseek_key_panel\web\index.html 也能用，
   只是数据会存在浏览器里而不是文件里。

Q: 为什么官方用量非要走本地服务？
A: platform.deepseek.com 的接口不带任何跨域响应头，
   OPTIONS 预检直接返回 405，浏览器会被同源策略拦死。

Q: 端口被占用怎么办？
A: 默认 8787，会自动往后试到 8798。也可以 python run_panel.py --port 9000。

Q: 用量页提示 Token 无效？
A: 网页登录态会过期，重新登录 platform.deepseek.com 再取一次。
